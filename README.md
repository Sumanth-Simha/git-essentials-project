# Student Expense Tracker

A simple web application built using Python and Flask to demonstrate Git, GitHub, CI/CD pipelines, and application deployment.

## Features
- Add student expenses
- View recorded expenses
- Simple and beginner-friendly interface

## Tech Stack
- Python
- Flask
- HTML & CSS
- SQLite

## Run Locally

**1. Clone the repository**
```bash
git clone https://github.com/Sumanth-Simha/git-essentials-project
cd git-essentials-project
```

**2. Create a virtual environment**
```bash
python -m venv venv
```

**3. Activate the environment**

Windows:
```bash
venv\Scripts\activate
```

Linux/macOS:
```bash
source venv/bin/activate
```

**4. Install dependencies**
```bash
pip install -r requirements.txt
```

**5. Run the application**
```bash
python app.py
```

Open `http://127.0.0.1:5000` in your browser.

## Deployment

The application is deployed using Render.

## Learning Objectives

This project is used to demonstrate:
- Git and GitHub fundamentals
- Branching and Pull Requests
- Continuous Integration (CI)
- Automated testing using GitHub Actions
- Continuous Deployment (CD)
